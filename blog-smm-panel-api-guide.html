How to Connect & Resell SMM Services via API v2 (2026 Complete Guide)

By GhBooster Engineering • Updated August 2026 • 8 min read

Scaling a Social Media Marketing agency or launching an automated reseller website requires instant, programmatic order submission. The GhBooster REST API v2 enables child panel owners and software developers to execute orders, fetch live pricing, and verify status in real-time.

1. Generating Your GhBooster API Key

Before making API requests, log in to your GhBooster Account Settings and navigate to the API section to copy your unique API Secret Key. Treat this key as confidential access credentials.

2. Core API Endpoints & Request Payload

All requests must be sent as HTTP POST requests to https://ghbooster.com/api/v2 using standard form-urlencoded or JSON parameters.

// Example: Submitting a new SMM order
POST /api/v2
Host: ghbooster.com
Content-Type: application/x-www-form-urlencoded

key=YOUR_API_KEY
&action=add
&service=104
&link=https://instagram.com/yourprofile
&quantity=1000
